# Code of Conduct

## Our Commitment

We are committed to providing a friendly, safe, and welcoming environment for all contributors regardless of:

- experience level
- gender
- nationality
- race
- religion
- identity

Everyone participating in this project is expected to follow this Code of Conduct.

---

# Expected Behavior

Participants should:

- be respectful
- provide constructive feedback
- communicate professionally
- focus on improving the project
- collaborate positively with other contributors

---

# Unacceptable Behavior

The following behaviors are not tolerated:

- harassment
- personal attacks
- discrimination
- abusive language
- intentional disruption of discussions

---

# Enforcement

Project maintainers have the responsibility to:

- remove inappropriate content
- warn contributors when necessary
- block contributors in severe cases

---

# Reporting Issues

If you experience or witness unacceptable behavior, please report it to the project maintainer.

All reports will be reviewed and handled appropriately.

---

# Acknowledgement

This Code of Conduct is inspired by open source community standards to ensure a healthy collaboration environment.
